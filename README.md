# A.W Ndung'u Law Advocates

A production-ready static website adaptation of the Cecilia Mwaura & Co. Advocates design template for A.W Ndung'u Law Advocates, Nanyuki.

## Included

- Cecilia-template navigation, hero, practice cards, counsel section, split image band, consultation band, insights, contact rail and footer.
- Mobile-first responsive breakpoints matching the template structure.
- A.W Ndung'u branding and supplied portrait.
- Supplied 4K/60fps logo animation plus an optimized animated WebP version used in-page for reliable mobile playback.
- Practice Areas, About, Alice Ndung'u profile, Insights, Contact, Privacy, Terms and 404 pages.
- SEO metadata, Open Graph image, LegalService schema, sitemap, robots.txt and web manifest.
- Google Maps embed for Fahari House, Nanyuki.
- WhatsApp, telephone, email, TikTok and LinkedIn links.

## Verification

Run:

```bash
npm run check
npm run build
```

The deployable output is written to `dist/`.
